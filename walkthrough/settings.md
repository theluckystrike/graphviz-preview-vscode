# Engine, colors and limits

- The default engine can be auto (the graph's `layout=` or dot), dot, neato, fdp, sfdp, circo or twopi.
- In dark themes, the default black lines and text use the editor colors. Colors you set in the graph stay as they are. The theme setting can turn this off.
- A layout that runs past the time limit is stopped, and VS Code stays responsive.
